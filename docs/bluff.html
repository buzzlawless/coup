Coup Bluffing Explorer

Heads-up, one influence each, no Ambassador. P1 may bluff; P2 is honest and cannot see P1's card. Every choice is shown with its value under exact equilibrium play, and how often an equilibrium strategy makes it. ← the no-bluffing explorer

      How to read it. At P1's decisions each option shows P1's win chance given the card it really holds, and how often an equilibrium strategy plays it with that card — a mix under 100% is a bluffing frequency. Equilibria are not unique, so an option marked equally good is worth just as much. A P1 option marked leaves equilibrium is one its real card never makes there: P2's belief follows the equilibrium, so it may then rule that card out, but P2's strategy caps what every card can win, so leaving never gains P1 anything. At P2's decisions each option shows P2's win chance by its belief, the only thing P2 can compute, with the true figure beneath. The belief panel is what P2 has inferred from everything P1 has claimed so far.

      How it is solved. P1's card matters only when a challenge is resolved, so each public position carries the set of results P2 can guarantee, as a vector over P1's four possible cards. That set does not depend on history; history enters only through P2's belief, applied as a weighted minimum. Strategies come from small linear programs solved in the page.
